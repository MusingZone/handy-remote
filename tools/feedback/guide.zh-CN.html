语音反馈使用说明

识别错了，花 10 秒报告一下；之后的分析、调整、验证都在后台完成，不会弹窗打断你。

一次反馈的完整流程

  1. 报告你
    刚说完发现有错：按你给 voice_feedback.py report 绑定的快捷键，或在 Handy Remote 托盘菜单里选择反馈上一次识别。 弹出的窗口里默认选中最近一条，直接把错的地方改对，Ctrl+Enter 提交。 勾选「替换上屏文字」时，只要光标仍在那段文字末尾，原窗口里的文字就会被直接改成你的修正版（不对可 Ctrl+Z）。
  2. 分析后台，约 1 分钟
    托盘图标出现 蓝点。后台把这条听写的文字、服务端当时的识别记录（草稿、原始与最终文本、耗时）和你的修正版交给所配置的分析器 （Copilot CLI 或兼容 OpenAI 接口的模型；录音只留在本机），判断是哪类问题，并只提出安全的改动：加热词、加替换规则、调流式参数； 需要改代码的问题记入待办。替换规则会先在你的历史听写里试跑，显示会影响多少条。
  3. 等你审阅你，有空时
    分析完成后蓝点变为 橙点。不用急，橙点会一直等你。 单击托盘图标打开改进建议，每条建议都写了理由，可信度高的已预先勾选。 选「应用所选」「全部拒绝」或「稍后再看」。
  4. 生效后台，几秒
    接受的改动写入服务端词库（服务端和本机都会先备份旧版本），服务端热加载，下一句话就生效，不用重启。
  5. 自动验证后台
    用新词库把你报告的那段录音重新识别一遍，和你的修正版比对。 效果变好或持平：什么也不提示。 只有变差或验证失败时，托盘才再出现橙点；单击图标即可看到说明。

托盘图标的含义

图标 含义 单击图标
普通图标 没有待办 打开 Handy Remote
蓝点 正在分析你刚提交的反馈 打开 Handy Remote（分析完会自动变化）
橙点 有改进建议待审，或有一条提醒 打开审阅窗口 / 提醒

托盘菜单里也有查看改进建议、反馈上一次识别和本说明的入口。

什么样的问题值得报告

  • 人名、产品名、英文术语总被写错：最容易通过热词或替换规则修好。
  • 某个词总被替换成同音字。
  • 标点明显不对：多了逗号、该断句没断。这类问题会调整断句参数或记入待办。
  • 漏字、吞字、延迟太大：会附带服务端记录，便于定位原因。

偶尔一次说得含糊导致的错误，不必报告。一条报告只针对一句话，修正版里只改错的地方，其余保持原样，分析会更准确。

数据放在哪里

  • 报告：%LOCALAPPDATA%\handy-remote\feedback\reports\（录音、你的修正版、分析结果和你的决定）， 除非在 reports_dir 里另行指定。
  • 本机词库备份：...\feedback\lexicon-history\；服务端另有自己的历史备份。
  • 需要改代码的待办：...\feedback\backlog.md。
  • 设置：%APPDATA%\handy-remote\feedback.toml（参见 feedback.example.toml）。
